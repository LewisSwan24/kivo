Kivo privacy policy

Last updated: 1 October 2026

What Kivo accesses

Kivo uses one Google permission: drive.file. With it, Kivo can create files in Google Drive and read or delete the files it created. It cannot see any other file in the connected Google account, and it does not ask for email, contacts or any other Google data.

What is stored

Videos that team members upload through the team's content tool are stored in one Google Drive folder. The tool's own database keeps a record of each upload: the Drive file id, the file name, its type, size, length and checksum, who uploaded it and when.

Who can see it

Only members of the project team, and the people the Drive folder is shared with. The data is not sold, used for advertising, or given to anyone else.

Google API data

Kivo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can remove Kivo's access at any time at myaccount.google.com/permissions. Files already uploaded stay in the Drive folder until someone deletes them.
